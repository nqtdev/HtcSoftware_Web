# Định danh điện tử (eKYC) - Trang web HTC Software

Dự án Website Định danh điện tử (eKYC) - [ekyc.dinhdanhdientu.vn](https://ekyc.dinhdanhdientu.vn).

## 🚀 Công nghệ sử dụng
- **Framework:** ReactJS (v18)
- **Build Tool:** Vite
- **Styling:** Tailwind CSS, Ant Design, Flowbite React
- **Animations:** GSAP, Motion, Animate.css, AOS
- **Khác:** Swiper (Slider), Lucide React (Icons), React Router DOM (Routing)

## 📋 Yêu cầu hệ thống
- Node.js (phiên bản mới nhất được khuyến nghị)
- Trình quản lý gói: npm hoặc pnpm hoặc yarn

## 🛠 Hướng dẫn cài đặt và chạy dự án

1. **Cài đặt các gói phụ thuộc:**
   ```bash
   npm install
   # hoặc pnpm install / yarn install
   ```

2. **Chạy server phát triển (Development):**
   ```bash
   npm run dev
   ```

3. **Build dự án (Production):**
   ```bash
   npm run build
   ```

4. **Xem trước bản build:**
   ```bash
   npm run preview
   ```
